# Live Chat

A real-time chat app with a modern, premium UI. Sign in with Google and chat instantly — messages appear live, and you can see when someone is typing.

**Live demo:** https://huzaifa-live-chat.vercel.app

## What it does

- Google sign-in (Firebase Auth)
- Real-time messaging (Firestore, no refresh needed)
- Typing indicator — see when someone is typing
- Modern dark UI with animated aurora background
- Works on mobile and desktop

## Tech

- HTML, CSS, JavaScript (single file, no build step)
- Firebase Auth + Firestore
- Deployed on Vercel

## Run it yourself

1. Clone this repo
2. Create a Firebase project and enable Google sign-in + Firestore
3. Put your Firebase config in `index.html`
4. Open `index.html` or deploy to Vercel

That's it — no npm install, no build.
