# Live Chat
A real-time chat app — join with your name and chat with anyone online.
**Live Demo:** https://huzaifa-live-chat.vercel.app
## Features
- Join with any username, no signup
- Messages appear for everyone in real time
- Messages stored in cloud storage, shared across all users
- Clean dark UI, fully responsive
## Tech Stack
- HTML5, CSS3, JavaScript
- Node.js (Vercel serverless functions)
- Vercel Blob for message storage
